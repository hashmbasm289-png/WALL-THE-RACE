# Wall Race 3D — تطبيق APK و EXE

## الطريقة (بدون أي تثبيت على جهازك)
1. أنشئ حسابًا مجانيًا على github.com ثم مستودعًا جديدًا (New repository).
2. ارفع كل محتويات هذا المجلد إلى المستودع (Add file → Upload files). تأكد من رفع مجلد `.github` أيضًا.
3. افتح تبويب **Actions** وانتظر 5–10 دقائق حتى ينتهي البناء.
4. افتح آخر عملية بناء ونزّل من **Artifacts**:
   - `WallRace-APK` → ملف `app-debug.apk` ثبّته على الأندرويد.
   - `WallRace-EXE` → ملف `WallRace3D.exe` يعمل مباشرة على ويندوز.

## ما الذي تغيّر
- الأندرويد: الاتجاه مقفول أفقيًا حقيقيًا (`sensorLandscape`)، يدور الجهاز تلقائيًا عند الدخول، وبملء الشاشة بدون أزرار النظام، ولا يطفئ الشاشة.
- ويندوز: ملء الشاشة تلقائيًا (F11 للتبديل).
- مكتبات three و peerjs تُضمَّن داخل التطبيق. اللعب الجماعي/لوحة الصدارة تحتاج إنترنت كما كانت.
